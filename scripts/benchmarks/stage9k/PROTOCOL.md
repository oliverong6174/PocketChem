# Stage 9K frozen protocol

The user's assignment is the specification. This is an independent evaluator of Claude Code's Stage 9J implementation, with knowledge of the reported failure categories. Selection is purposive, model-authored and not statistically representative. No detailed prediction logic was read and no PocketChem prediction was run before the freeze. Reading existing protocols, schemas, runners and test adapter interfaces was permitted. Standalone RDKit molecular parsing/canonicalization is not a chemistry prediction.

## Evidence and denominators

`cases.json` is final ground truth. `candidate-cases.json`, `source-exclusions.json`, `case-exclusions.json` and `overlap.json` preserve the selection trail. No reference answers may change after predictions. A = exact PubChem identity/name pair or NIST EI spectrum cross-checked against PubChem formula. PubChem names are computed database names, not a unique legal IUPAC spelling. B = independently reasoned application of an explicit OpenStax general rule to a novel substrate; no exact-case experimental validation. **B scores are provisional and must not be merged into A reference-validated scores.** Insufficient evidence excludes a case from A. No primary experimental paper is claimed.

Novelty excludes primary substrate constitutions present in any 9F/H/I/J JSON case or saved database snapshot (results directories excluded). Canonicalize with standalone local RDKit, remove `@`, `/`, `\` before constitutional canonicalization. Common structural reagents do not disqualify a case. Product overlap is recorded separately. Internal homologues, scaffolds, paired stereoisomers, shared products, and reaction families cause correlation; report nominal Wilson intervals with this limitation. The screen is structural, not a claim of chemical-family novelty.

Each case lists structures, conditions, reference answer, source, evidence quality, applicable criteria and uncertainties. The criterion definitions below apply to every case listing that criterion. Separate dimensions retain all eligible cases in their denominators, including unsupported, unresolved, timeout and execution-error cases. No global accuracy.

## Fixed scoring

`scoring.mjs` is authoritative. Names: normalize case, whitespace and hyphens only; preserve descriptors, locants and the entire emitted systematic name. A finite accepted list produces a conservative lexical score. Wrong lexical spelling is `lexical-mismatch`, not proof of wrong chemistry. Molecular identity independently resolves the full emitted name through one PubChem request, without retries, or uses an exact frozen accepted name/structure pair; compare isomeric canonical structures. Unresolvable names remain unresolved. A stereo-specified name case also requires the same isomeric identity. Unsupported naming is abstention. Formula correctness alone is not molecular identity.

MS: parent m/z only when the library parent intensity is >=1% of its base peak; tolerance 0.5 m/z. Do not infer absence from a weak/absent reference parent. Base peak: any tied maximum in the frozen library spectrum within 0.5 m/z; null output is abstention. Keys: top three peaks >=20% excluding the base, parent and parent+1/+2; require every key to have a positive predicted peak within 0.5 m/z. Report strict per-case success and micro peak recall separately; no intensity calibration is claimed. Downloaded spectra do not specify electron energy; no 70 eV claim.

Reactions: exact constitutional target occurrence measures connectivity coverage; this is not selectivity accuracy. Regiochemistry additionally requires no competing forbidden/minor constitution at the same unranked level; an explicit correct major can establish the preference. Ranking requires both expected major and minor products with the correct labels; a missing minor cannot pass. Stereo: canonical isomeric comparison on products with the expected constitution; unspecified stereo is incomplete, any wrong specified diastereomer fails. For racemic substrates either correct enantiomer depiction suffices for relative stereochemistry; record complete racemate enumeration separately. No E/Z score is inferred from a wedge count. Scores are B only.

Routes: seeded one-step route-quality assessment, not search efficiency or optimality. `flag` is detected only by known-concern/contradicted; `clear` is specific when neither occurs. Keep fixed positive/negative denominators. Report end-to-end flagging and the separate subset whose structural replay is verified. Preserve every quality finding so structural failures cannot masquerade as chemical-quality sensitivity. Plausible-incomplete is not a positive chemical-support claim. Scores are B only.

Report each dimension with correct / fixed N, all outcome categories, and 95% Wilson intervals, using z=1.959963984540054. Intervals quantify binomial sample size only, not case-selection bias or homolog correlation. Report coverage and abstentions per capability/dimension. Harness errors are not automatically chemical failures.

## Execution and freezing

Engine starting commit and `src` tree are recorded in `manifest.json` and `starting-state.json`. Freeze all pre-run files by raw-byte SHA-256, with newline conversion disabled by local `.gitattributes`. Commit the manifest and files separately from results. Record the freeze commit afterwards. `run.mjs` verifies all frozen hashes and the src tree; RUN-LOCK is created exclusively **before** the first case. One isolated Node process per case, sequential, one attempt, 45 s hard process deadline. Logs and full outputs persist per case, plus append-only raw JSONL. Do not remove the lock or retry a failed case. Fatal infrastructure failures and dependency limitations must be retained and classified.

Names/MS use the public existing Node/Vite test adapter. Reactions call pathway listing once on the substrate plus predeclared cyanide, iodide or ethoxide structures, then frozen family filters match rule metadata. No target-based second listing or tuning. The interface cannot accept solvent/temperature, so condition-dependent conclusions are limited. Route assessment runs the requested rule once, uses the planner's step converter when its output matches the submitted product, otherwise submits a manual route; then runs replay, compatibility, selectivity and quality assessment. Replay itself invokes the production rule machinery as part of verifying the submitted route. No older scientific holdout is run.

Post-run name resolution calls an external reference, not PocketChem. It does not change ground truth or lexical scoring. All raw outputs remain immutable; offline scoring creates a separate exclusive output. No engine fixes in this stage.
