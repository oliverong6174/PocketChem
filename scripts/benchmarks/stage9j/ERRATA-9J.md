# Stage 9J errata (append-only)

Nothing in Stage 9F, 9H or 9I result files, scores or ground truth was edited. Each item below is a methodological correction recorded beside the original.

1. **Stage 9I errata-aware nomenclature scoring accepted different stereoisomers.** Its equivalence stripped every CIP descriptor and every cis/trans, so `(R)-` and `(S)-` names compared equal. Stage 9J adds `nameEquivalence.mjs` (descriptors compared, lexical synonyms only; 28 positive/negative tests) and re-scores without touching the 9I file: `results/nomenclature-strict.json` (9I engine rows) and `results/nomenclature-current.json` (current engine). The same stripping and a parenthesis split had also let a *right trivial name beside a wrong systematic name* count as correct: nicotine was displayed as "(S)-3-1,4-diaminobutylpyridine (nicotine)" with High confidence. That name is now withheld (ring-count guard). The frozen 9H rule therefore reads 33 correct for the current engine (Stage 9I reported 34); the lost case is that nicotine name.
2. **Stage 9I "pre-existing, fails identically on main" Diels-Alder depiction check was a real defect, not a presentation quirk.** The engine drew the exo adduct (ester trans to both methyls) for an activated dienophile. Verified by an independent SMILES-parity argument (rule validated on 1,2-dimethylcyclohexane) before and after the fix. The regression case was renamed `DA-dimethyl-diene-acrylate-all-cis-three-wedges` and now expects 3 wedge / 0 dash (the all-cis adduct); the mirror projection 0/3 is the same racemate. The "documented pre-existing failures" list is now empty.
3. **Stage 9E test assertion changed.** `mechanism9e.test.mjs` pinned propylene oxide + methanol/H+ to the single product 1-methoxypropan-2-ol. With no tertiary, benzylic or allylic carbon the opening has mixed SN1/SN2 character, so both regioisomers are now kept (unranked). The tertiary assertion was added beside it. This replaces an over-claim; it is not a relaxation of any other assertion.
4. **Route-quality validation set label error (N01).** Case N01 (radical bromination of propane to 2-bromopropane) was labelled `not-supported`. Bromination is highly selective for the secondary C-H, so the engine's "major" and a `chemically-supported` tier are defensible; the label was the author's error and stays in the frozen file. It is counted as a labelling error, not as an assessor false positive.
5. **Route-quality harness v1 under-reported selectivity.** The first run (`results/first-run.json`, preserved unchanged) built steps with a test fixture that drops `selectivityAssessment`; harness v2 uses the planner's own `forwardStepFromPathway`. Case-target construction (largest product component) was also corrected for multi-product steps. The cases were never edited. Runs 2 and 3 are appended, not substituted.
6. **Scope statements that stand.** The 9H cases remain exposed, the 9I MS set is development-guided, and Stage 9J set B (8 cases) and the route-quality set were authored by the engine author: none of this is a blind or independent generalisation result.
