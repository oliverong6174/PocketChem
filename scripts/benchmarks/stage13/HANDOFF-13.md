## 3. Mechanics scientific model (`utils/physics/mechanics.ts`)
Analytic 2-D constant-acceleration kinematics for a point particle; no integration, so no drift. Projectile mode: x₀, launch height y₀ ≥ 0, speed, angle −90…90° (cos/sin snapped so vertical/horizontal launches have exact zero components), g 0.1–30 m/s², ground at y = 0, no drag. Constant-acceleration mode: independent ax, ay, optional ground, observation window. Landing is the first positive root of ½a·t² + v·t + y₀ = 0 (cancellation-free quadratic), with explicit handling of: y₀ = 0 and not rising (lands at t = 0, "no flight"), linear descent, never landing (upward acceleration, no ground), first-crossing when the acceleration would bring the particle back. Outputs: state at any time (position, velocity, acceleration, displacement, speed), time of flight, range (only when it lands), maximum height and apex time (only when it is a turning point), best range angle from a height (tanθ = v/√(v²+2gy₀)), specific energy ½v² + gy.

## 5. Circuit-analysis model (`circuits.ts`, `circuitLayout.ts`)
One ideal DC source (0–1000 V) driving a series/parallel **tree** of ideal resistors (1 mΩ–1 GΩ, ≤ 12 resistors, ≤ 4 nested levels). The tree is the circuit: the analysis (equivalent resistance, source current, per-part V, I, P, current share), the KCL/KVL/power checks, the diagram and the editor all use it. Convention: conventional current leaves + and flows left→right; V = V(left) − V(right) > 0. The layout emits integer-coordinate wires, so the drawing can be turned back into a netlist. Unsupported topologies (bridge, non-tree) cannot be expressed and any malformed or non-series/parallel record is rejected, never approximated. The structured editor adds/removes resistors, toggles groups series↔parallel, nests groups (group with one part collapses; the last resistor cannot be removed), with presets.

## 6. RC transient (`rc.ts`)
One source, one resistor, one capacitor, one loop, switch closing at t = 0: vC = Vs + (V₀ − Vs)e^(−t/τ), i = (Vs − V₀)/R·e^(−t/τ), U = ½CvC². Initial (V₀) and final (Vs) voltages are separate inputs; charging, discharging and "no transient" are distinguished; τ, half-way and 99 % times, source work = ΔU + resistor heat. Plotted span 3/5/7/10 τ; axes use SI prefixes; playback is Slow 12 s / Normal 6 s / Fast 3 s for any τ (1 ns … 10⁶ s). It does not model several capacitors, loops, inductors or non-ideal parts, and says so.
