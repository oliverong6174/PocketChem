# Stage 9H fresh independent evaluation: protocol (frozen before any frozen case is run)

Purpose: measure how PocketChem (engine as of Stage 9G) performs on cases that were **not** used for development, **not** part of the exposed Stage 9F holdout, and whose expected answers come from an independently inspectable reference. This is a validation stage. No production chemistry may change between the freeze and the one baseline run, and none may be tuned to these cases afterwards in Stage 9H.

## 1. Engine under test
`manifest.json` records `engineCommit` (the git commit at freeze) and `engineSrcTree` (`git rev-parse HEAD:src`). `run.mjs --final` refuses to run unless `HEAD:src` equals that tree and `src/` has no uncommitted change, so the freeze commit may add only evaluation files. Stage 9G ended at `1c307fd`.

## 2. What is frozen
Everything under `cases/`, `snapshots/`, `tools/`, `smoke/`, `selftest/`, `scoring.mjs`, `run.mjs` and this file, hashed with SHA-256 in `manifest.json` (line endings normalised). `run.mjs` recomputes every hash before running and refuses to start on any mismatch. After the single run it writes `results/final-lock.json`, and refuses to run again while that file exists. Raw per-case records are appended to a JSONL file as each case completes, so a crash does not lose or rewrite earlier predictions.

## 3. Authorship, independence and its limits (stated, not hidden)
* All case selection and authoring was done by one model session (Claude Sonnet 5.5) acting as author **and** evaluator. No subagent was launched (Stage 9G recorded that delegated authoring was blocked by a hook; this stage did not attempt to bypass any permission).
* Expected answers come from fetched, saved sources (below), not from PocketChem output. PocketChem was not executed on any frozen case before the freeze.
* The author did **not** read engine chemistry source this stage. The author did read the Stage 9F runner (adapter API names), Stage 9F reports, Stage 9F synthesis case titles, and has memory notes summarising Stage 9E/9G work. That is a real but limited route for bias in molecule *selection*; it is mitigated, not eliminated, by the exclusion rule in section 4.
* Model-authored selection is independent of PocketChem code, **not** of model error. Name-to-structure pairs in reactions were cross-checked against PubChem name resolution (64 of 64 matched); reaction product choices rest on the quoted sentence.
* One harness shakedown ran the engine before the freeze (`run.mjs --smoke`, seven one-off cases in `smoke/`). It was meant to use unrelated molecules, but the manifest check shows six of them (acetone, ethanol, 1-butanol, hexane and the acetone/propene reactants; see `smokeOverlapWithFrozenCases` in `manifest.json`) also occur in frozen cases. The author saw those engine outputs (for example the displayed name for acetone and the pathways offered for propene + HBr) but not scored against any frozen reference, and no engine code changed. This is a small, disclosed contamination of molecule-level independence for those few cases. The shakedown found two scoring-rule gaps, both fixed **before** the freeze and visible in `scoring.mjs`/`run.mjs`: (a) names shown as "systematic (common)" are accepted when either part is an accepted name; (b) a pathway that needs an extra condition the case does not list (peroxide, light, NBS, carbene source) does not claim the case.

## 4. Case inclusion criteria (set before selecting final cases)
1. **Novelty.** A molecule (nomenclature, properties, MS, IR) is excluded when its constitution (stereo-stripped canonical SMILES) occurs anywhere in a Stage 9F case file. A ranking set is excluded when its molecule set equals a Stage 9F ranking set. (`tools/stage9f-smiles-exclusion.json`.) Reactions and syntheses were written from new sources; overlap with Stage 9F reaction/synthesis cases was avoided by choosing different substrates and targets, but was not machine-checked.
2. **Reference.** A case is *scored* only if its expected answer is one of: `reference-database` (a saved PubChem or NIST record, values copied programmatically), `reference-secondary` (a saved Wikipedia table that cites a primary source), `verified-textbook-direct` (a sentence in the saved OpenStax text that names the substrate and the product; the quote is located programmatically in the saved file). Everything else is `rule-derived-provisional`: run and reported, never counted in a validated accuracy figure.
3. **Quality filters, applied mechanically.** Ranking by experimental value: all sources agree within a stated spread (bp 3 C, pKa 0.3, basicity 0.3, log Kow 0.5) and adjacent members differ by at least a stated gap (bp 8 C, acidity 0.5, basicity 0.8, log Kow 0.7, sigma 0.05). logP is scored only when listed experimental values agree within 0.5. MS: NIST and PubChem formulas must match. IR: formula match; a band is scored *present* only if the group is present by SMARTS and the saved gas-phase spectrum shows it (window maximum at least 12% of spectrum maximum), *absent* only if the group and obvious overlapping groups are absent and the window maximum is at most 3%; ambiguous bands are excluded and listed. Rejected candidate sets and the reason are printed by the build tools.
4. **Coverage aims (not padded; the final report states which were actually achieved).** Common substrates; unusual ones present in the nomenclature/property set (bicyclo[2.2.2]octane, spiro[4.4]nonane, ionic salts such as sodium acetate and ammonium chloride, terpenoids, stereo-specified lactic acids, alanine, limonene, carvone, cis/trans-1,2-dimethylcyclohexane); isomer families (2- vs 3-methylbutanoic acid, 1- vs 2-nitropropane, 3-bromopentane vs 1-bromo-2-methylpropane in MS, o/p/m chloronitrobenzene SNAr triad, 1,2-epoxypropane vs 2-methyl-1,2-epoxypropane); ambiguous conditions (mixed aldol, 1,2- vs 1,4-addition, carbocation rearrangement mixtures); competing outcomes (E2 vs SN2, Friedel-Crafts rearrangement, Hofmann vs Zaitsev); possibly unsupported chemistry (organocuprate, benzyne, Wittig ylide, SNAr, Sandmeyer); difficult synthesis searches (4-step acetylene routes, Stork enamine, order-sensitive aromatic substitution with a forbidden intermediate). Sixty-seven candidate compounds were removed by the novelty rule, so very common compounds (acetone, aniline, aspirin, caffeine...) are under-represented by construction.

## 5. Capabilities, sources and denominators
| Capability | Cases (scored / provisional) | Source |
|---|---|---|
| Nomenclature (name, constitution name, systematic name) | counts in `manifest.json` | PubChem PUG REST record (Lexichem name; query name also accepted) |
| Properties: formula, MW (0.1), exact mass (0.005), charge; logP (1.0) | " | PubChem; experimental log Kow from PubChem |
| Ranking (order per case; pairwise detail) | " | PubChem experimental values; Hammett table (Wikipedia, citing Hammett 1937) |
| Mass spectrometry: molecular ion, base peak, strict key-fragment set, M+2 | " | NIST WebBook JCAMP EI spectra |
| Infrared: present bands, absent bands | " | NIST WebBook gas-phase JCAMP + Wikipedia correlation table windows |
| Reactions: connectivity, regiochemistry, ranking (major/minor), ambiguity, stereochemistry | " | OpenStax Organic Chemistry modules |
| Synthesis: route discovery, verification, length, avoidance | " | OpenStax worked synthesis examples |

Not evaluated: **NMR** (no independently fetchable reference with permissible access was found; Stage 9F NMR counts came from a topological algorithm, which is not an independent reference). Not evaluated: stereochemical *naming* beyond the nine stereo-specified nomenclature cases; reaction yields.

Denominators are fixed in `manifest.json`: a reaction dimension applies to a case iff the case's `criteria` list names it; if the engine gives no verdict for an applicable dimension (e.g. no pathway claims the reagents), the analysis counts it as *abstained/unclaimed*, never silently dropped. Synthesis is scored out of the scored (textbook-direct) cases only. Percentages are always reported with 95% Wilson intervals; with 6-50 cases per dimension a 1-2 case difference is noise.

## 6. Scoring rules (implemented in `scoring.mjs`, tested by `selftest/scoring.test.mjs`)
Each dimension is reported separately; none is merged. Statuses: correct, wrong (wrong-flagged / wrong-confident for names), partially correct (fragment recall is recorded alongside the strict fragment verdict), incomplete (stereo unspecified), abstained (engine declines, or no pathway claims the reagents, or ranking unranked), unsupported (name status "unsupported" is scored as abstained), timed out (synthesis deadline or harness watchdog), engine-error. Details: nomenclature uses normalised exact match (case, spaces, dashes) against accepted names; ranking is pairwise order, ties must not be invented; MS fragments are strict (all listed peaks within 0.5 m/z) with recall recorded; IR present bands must have an engine peak within 20 cm-1 of the table window, absent windows must contain no diagnostic/supporting engine peak; reactions follow the Stage 9F harness-v2 logic (reagent tokens select the pathways that count, a second listing with fixed reagent molecules is tried when the substrate-only listing does not claim the reagents or lacks the reference product) with the extra qualifier rule in 3(b); synthesis uses the production 45 s deadline (no `totalMs` override), the case's stated stoichiometric `copies`, and a 120 s harness watchdog.

Synthesis failure causes (missing rule, insufficient reactants, copy count, search failure, timeout, replay failure, questionable route) are assigned **after** the run, from the raw route/outcome logs, and the assignment is a documented judgment, not a harness verdict.

## 7. Procedure
1. Fetch sources, build cases (tools/), commit nothing yet. 2. Harness shakedown (smoke) and scoring self-test. 3. Write this protocol, compute `manifest.json`, commit the frozen artifacts, record the freeze commit in `results/freeze-record.json`. 4. `node scripts/benchmarks/stage9h/run.mjs --final`, once. 5. Analysis (`analyze.mjs`) reads only the saved raw/final records. 6. Defects are documented for later; production code is not touched and nothing is rerun.

## 8. Known limitations (declared up front)
Secondary sources (PubChem is a compilation; OpenStax is a textbook; Wikipedia table is 1937 constants) rather than primary literature; no primary paper was opened this stage. Sample sizes are small per dimension. Selection was by one author. The reagent-molecule table in `run.mjs` is a guess at what the Reactions page requires and may turn some abstentions into harness artefacts; this is reported where it matters. Gas-phase NIST IR differs from condensed-phase spectra. Heuristic engines are not validated as experimentally exact by any result here.
