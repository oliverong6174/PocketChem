## Phase A: classification of 9H failures
* Nomenclature (26 non-correct): scoring/synonym defects 11 (ethanoyl, methanoate, `(R)` vs `(2R)`, cis/trans repeat, parentheses, ring locant 1); engine defects 8 (aryl ketone parent, ethenyl/ethynyl, `e` elision, citric-acid parent, salt cation dropped, phenylhydrazine read as aniline, anthracene read as naphthalene, plus guards); unsupported chemistry 7 (biphenyl, diphenylamine, camphor/bicyclo, spiro, phthalic anhydride, quaternary ammonium salt) - these still abstain.
* MS: base peak/fragment failures are mostly model limits (no H-rearrangement ions, M+• over-weighted for saturated aliphatics), not scoring defects.
* Synthesis: "found" was read as "sound"; the planner and replay were behaving as designed.

## Phase B: route quality (`routeQuality.ts`, tests `routeQuality9i`)
Structural replay is reported unchanged (`quality.structural`); a separate tier is added: structure-verified / chemically-supported / plausible-incomplete / known-concern / contradicted. Checks (generic, no molecule exceptions): atom sourcing (documented reagents such as HBr or Ph3P are distinguished from structural partners; unsourced elements or carbon contradict), over-halogenation of free arylamine/phenol, nitration of free arylamine, Friedel-Crafts polyalkylation, beta-keto acid intermediates, beta-halo/enolizable electrophiles under base, and classification of unranked outcomes (EAS regioisomers, equal-substitution Markovnikov, radical-halogenation mixtures). Findings on the 9H routes: SY-10 and SY-05 known-concern; SY-07 known-concern (beta-keto acid); SY-06 known-concern (beta-halo ketone); SY-01 depends on which route the time-limited search returns (Wittig route: HBr to pent-2-ene regio-mixture; alkane-bromination route: radical mixture). The Wittig ylide carbon comes from the alkyl-halide partner, which replay already requires; Ph3P is documented-not-tracked. A false-positive sweep over 466 real engine pathways found 0 unsourced-atom flags after abbreviation handling. The UI shows the tier beside structure verification; saved routes without it are labelled not assessed; synthesis saved-result version is now 2.
Limits: `chemically-supported` is deliberately rare (needs declared conditions for every step); absence of a finding is not evidence of success; search results on this machine varied run to run (3.5 s vs 22 s, different route for SY-01) independent of these changes (verified by stashing the attach points).

## Phase C: nomenclature
Exposed 9H cases, 9H scorer unchanged: 26/52 -> 34/52 correct, confident-wrong 6 -> 0. With documented synonym equivalences (never applied to the original numbers): 45/52 correct, 7 abstained, 0 wrong. Fixes: ethenyl/ethynyl; ketone locants and one-carbon parents; exocyclic ketones named as ketones; ring ketones (cyclohexanone was previously withheld); enone vs acrolein/acrylic-acid SMARTS (root cause of MVK numbering and fumaric acid read as acrylic acid); `e` elision; tri+carboxylic acids; simple salts; guards that withhold names dropping N-N, C=O, aromatic heteroatoms, phantom unsaturation, or whole components; templates may not swallow fused rings. Side effect: more structures now abstain instead of printing wrong names (fumaric/maleic, phenylhydrazine, benzhydrol). References: IUPAC 2013 Recommendations P-14.3, P-16.7, P-32.3, P-44.1, P-64.3, P-65.1, P-73. Tests: `nomenclature9i` (66), regression suites unchanged except aliases added for locant-bearing ketone names.

## Phase D: mass spectrometry
Added mechanism-derived McLafferty ions (m/z = acceptor-side fragment + transferred H: 60 acids, 74 methyl esters, 41 nitriles...), alcohol alpha-cleavage weighting by largest radical lost, molecular-ion cap for saturated acyclic compounds >= 6 heavy atoms, and `basePeakCertainty` (supported / heuristic / unreliable) with candidate m/z list, shown in the Spectroscopy page. Fresh 15-case NIST development set (`ms-dev`, frozen before the baseline run): molecular ion 6/6 -> 6/6, base peak 3/15 -> 4/15, strict fragments 3/15 -> 3/15. The base-peak accuracy gain is small and within noise; the real change is that 10/15 saturated-aliphatic cases are now labelled `unreliable` instead of presented as predictions, while the only `supported` case (butyl acetate) is correct. Remaining unsupported: H-rearrangement alkyl/alkenyl ion families (41, 55, 56...), quantitative intensities. Spectroscopy saved-result version raised to 3.
